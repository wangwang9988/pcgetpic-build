# 文档写入技能

当用户在讨论后要求把方案、评估报告、分析结论等内容写成 Markdown 文档时，按本规则保存。

## 触发条件

当用户说以下内容时触发（命中任一词即触发）：
- "写成md文件"、"写成文档"、"保存为md"、"输出到文档"
- "将方案写成md文件"、"将评估报告写成md文件"、"将分析写成md文件"
- "将你的方案写成md文件"、"将你的评估报告写成md文件"
- "仅制定方案"、"只制定方案"、"仅做方案"、"只做方案"

## 重要原则：仅写方案，禁止修改代码

本技能的核心目的是**将讨论内容写成 Markdown 方案文档，而非修改代码**。触发本技能后：

- ✅ 只做：将方案、评估报告、分析结论等内容整理并保存为 md 文件
- ❌ 禁止：修改项目中的任何代码文件（包括但不限于 .js、.ts、.vue、.json、.css、.html 等源码文件）

用户的意图是输出方案文档，不是既写方案又改代码。即使方案中涉及代码示例，也仅作为文档内容写入 md 文件，不修改项目源码。

## 文件保存规则

### 1. 保存位置（严格限定）

- **必须**：当前项目根目录的 `docs/` 文件夹 **根目录**
- ❌ **禁止**：保存到 `docs/` 的任何子目录（如 `docs/technical/`、`docs/权限新增后的工作/` 等）
- 若 `docs/` 不存在，先创建该文件夹（不要创建子目录）

### 2. 文件名规则

格式：`<中文名>_<五位随机小写字母>.md`

- **中文名**：根据内容主题命名，简洁达意（如 `登录方案`、`权限新增评估`、`采集脚本重构方案`）
- **下划线** `_` 连接中文名与随机字母
- **五位随机小写字母**：由你直接给出，不使用任何工具生成（每次给出不同组合，仅限小写 a-z）
- 扩展名 `.md`

示例：`权限新增评估_plxwa.md`、`采集脚本重构方案_kxqwm.md`

### 3. 重名检查

生成文件名后，检查 `docs/` 目录是否已有同名文件：
- 已存在 → 重新生成五位随机小写字母，直到不重名
- 不存在 → 使用该文件名

### 4. 随机字母生成

直接给出五位小写英文字母组合（仅 a-z），不使用任何工具，每次生成不同的组合。目的为防止与同事的文件重名。

## 执行步骤

1. 确定保存目录（**固定为 `docs/` 根目录**，忽略用户指定的子目录要求，告知用户已统一保存到 docs/ 根目录）
2. 根据内容主题生成中文名
3. 直接生成五位随机小写字母
4. 拼接文件名：`<中文名>_<随机字母>.md`
5. 检查 `docs/` 目录是否已有同名文件，如有则重新生成随机字母
6. 将内容写入文件（UTF-8 编码，内容完整、结构清晰）
7. 向用户报告完整文件路径

## 注意事项

- 五位随机小写字母的目的是防止与同事的文件重名
- 文件一律保存到 `docs/` 根目录，不要创建或使用任何子目录
- 中文名应简洁准确反映内容主题，不要过长
- 本技能不修改任何代码文件，只产出方案文档
