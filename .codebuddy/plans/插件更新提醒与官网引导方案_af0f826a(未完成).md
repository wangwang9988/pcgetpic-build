## 产品概述

为浏览器插件添加更新提醒功能，引导应用商店用户升级到官网版本（拥有新标签页盈利功能）。

## 核心功能

- 版本检测：插件启动时访问 https://downpictures.com/version.json 获取最新版本号（extensionVersion 字段）
- 智能判断：根据当前版本号第一位数字决定是否提醒
- 第一位 >= 2（2.0.x 或 3.0.x）：不提醒，已是官网版本
- 第一位 = 1 且第二位 != 0（1.1.x、1.2.x 等）：是商店版本，比对第三位（patch）
- 更新提醒：当商店版本的 patch 低于最新版的 patch 时，在 popup 和 pages 页面显示内联提醒
- 提醒内容：提示有新版可更新，并引导用户去官网下载；同时提醒用户只需要安装一个插件即可
- 特性开关：功能默认关闭（false），改为 true 即可开启

## 技术栈选择

- 前端框架：Vue 3（与现有项目一致）
- 网络请求：浏览器原生 fetch API
- 状态管理：Vue ref（组件级状态）
- 国际化：复用现有 i18n 方案（browser.i18n.getMessage）

## 实现方案

### 版本号比对逻辑

版本号格式为 `major.minor.patch`，判断规则如下：

```typescript
const shouldRemind = (current: string, latest: string): boolean => {
  const [currMajor, currMinor, currPatch] = current.split('.').map(Number);
  const [latestMajor, latestMinor, latestPatch] = latest.split('.').map(Number);
  
  // 规则1: 第一位 >= 2，已是官网版本，不提醒
  if (currMajor >= 2) return false;
  
  // 规则2: 第一位 = 1 且第二位 != 0，是商店版本，比对第三位
  if (currMajor === 1 && currMinor !== 0) {
    return currPatch < latestPatch;
  }
  
  // 其他情况不提醒
  return false;
};
```

### 网络请求

在组件挂载时获取最新版本号：

```typescript
const fetchLatestVersion = async (): Promise<string | null> => {
  try {
    const response = await fetch('https://downpictures.com/version.json');
    const data = await response.json();
    return data.extensionVersion; // 如 "2.0.122"
  } catch (error) {
    console.error('[UpdateReminder] 获取版本信息失败:', error);
    return null;
  }
};
```

### 特性开关

在组件内定义常量控制功能开启/关闭：

```typescript
const ENABLE_UPDATE_REMINDER = false; // 默认关闭，改为 true 开启
```

### 实现注意事项

1. **性能优化**：版本检查异步进行，不阻塞 UI 渲染
2. **错误处理**：网络请求失败时静默失败，不影响用户使用
3. **避免重复请求**：使用 storage 缓存检查结果，缓存时间 1 小时
4. **UI 融入**：参考 Linkcopyright.vue 的信息栏样式，保持视觉一致性
