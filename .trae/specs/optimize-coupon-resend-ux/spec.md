# 优化重发优惠券交互 + 优惠券详情弹窗 Spec

## Why
当前"重发优惠券"按钮在优惠券有效时直接重发旧券，管理员不知道发了什么；重复发放警告后仍直接重发而非新建；管理员无法查看某订单所有优惠券的详细信息。

## What Changes
- "重发优惠券"按钮：优惠券有效时，确认弹窗显示当前优惠券信息（面值、有效期）
- 重复发放警告：点击"继续发放"后弹出新建抵扣券对话框，而非直接重发旧券
- 新增后端接口：查询某订单所有优惠券列表
- 优惠券列：点击状态标签弹出所有优惠券详情弹窗

## Impact
- Affected code:
  - `server/src/routes/admin/orders.ts` — 新增优惠券列表查询接口
  - `admin-panel/src/api/orders.ts` — 新增 API 函数和类型
  - `admin-panel/src/views/Orders.vue` — 修改重发逻辑 + 新增优惠券详情弹窗

## MODIFIED Requirements

### Requirement: 重发优惠券交互优化
当前"重发优惠券"在优惠券有效时直接重发，管理员不知道发了什么内容。

#### Scenario: 有效券重发时显示券信息
- **WHEN** 管理员点击"重发优惠券"且优惠券有效（非过期）
- **THEN** 确认弹窗显示当前优惠券信息："当前抵扣券面值 XX 元，有效期至 YYYY-MM-DD，确定要重发至 xxx@xx.com 吗？"

#### Scenario: 重复发放警告后新建优惠券
- **WHEN** 管理员点击"重发优惠券"且 coupon_count >= 2，弹出重复发放警告后点击"继续发放"
- **THEN** 弹出新建抵扣券对话框（与过期时相同），而非直接重发旧券

## ADDED Requirements

### Requirement: 优惠券详情弹窗
管理员点击优惠券列的状态标签，可查看该订单所有优惠券的详细信息。

#### Scenario: 点击优惠券标签查看详情
- **WHEN** 管理员点击优惠券列的状态标签（如"有效(共3次)"）
- **THEN** 弹出该订单所有优惠券列表，每张券显示：券码、面值、状态、创建时间、过期时间

#### Scenario: 无优惠券时不可点击
- **WHEN** 优惠券列显示"-"
- **THEN** 不可点击
