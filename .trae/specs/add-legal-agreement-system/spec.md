# 法律信息与用户协议体系 Spec

## Why
软件目前缺乏合规的用户协议告知机制：现有"用户协议"按钮位于状态栏一级入口，过于显眼且不符合隐蔽性要求；协议内容简略（仅6条），未充分整合授权方案文档中的法律风险防控要点；缺少首次安装时的协议告知弹窗，存在因未履行告知义务而导致的合规风险。

## What Changes
- 将状态栏的"用户协议"按钮移至三级菜单深处（下载设置 → 关于 → 法律信息），降低视觉暴露
- 基于现有协议文档（V4.0版本）和授权方案文档，重写用户协议内容，强化法律责任界定
- 新增首次安装使用时的低视觉干扰协议告知弹窗，履行告知义务
- 新增 localStorage 标记机制，记录用户是否已阅协议

## Impact
- Affected code: `StatusBar.vue`（移除按钮）、`DownloadSettings.vue`（添加"关于"子区域）、`UserAgreementDialog.vue`（重写协议内容+改造弹窗模式）、`App.vue`（挂载首次安装弹窗逻辑）
- Affected components: 新增 `FirstLaunchAgreement.vue` 首次安装告知弹窗组件

## ADDED Requirements

### Requirement: 三级菜单法律信息入口
系统应在至少三级菜单内提供"法律信息"入口，设计应保持隐蔽性。

#### Scenario: 用户通过三级菜单查看法律信息
- **WHEN** 用户依次展开侧边栏 → 下载设置折叠面板 → 关于子区域
- **THEN** 可见"法律信息"文字链接，点击后打开完整用户协议弹窗

#### Scenario: 法律信息入口不显著
- **WHEN** 用户正常使用软件
- **THEN** "法律信息"入口不在一级或二级界面直接可见，需主动展开折叠面板并滚动至底部才可见

### Requirement: 首次安装协议告知弹窗
系统应在用户首次安装启动时弹出协议告知弹窗，履行告知义务。

#### Scenario: 首次安装启动
- **WHEN** 用户首次安装并启动软件（localStorage 中无 `downpictures_agreement_seen` 标记）
- **THEN** 在主界面加载完成后，显示低视觉干扰的协议告知弹窗

#### Scenario: 弹窗视觉设计
- **WHEN** 首次安装告知弹窗显示
- **THEN** 弹窗采用半透明毛玻璃风格，尺寸适中（约400px宽），不使用醒目颜色或大号字体，整体视觉权重低于激活弹窗

#### Scenario: 点击弹窗区域查看完整协议
- **WHEN** 用户点击弹窗内部区域（非关闭按钮）
- **THEN** 打开完整用户协议弹窗供用户阅读

#### Scenario: 点击弹窗外部关闭
- **WHEN** 用户点击弹窗遮罩区域
- **THEN** 弹窗自动关闭，同时标记 `downpictures_agreement_seen=true`

#### Scenario: 非首次启动不再弹出
- **WHEN** 用户再次启动软件（localStorage 中已有 `downpictures_agreement_seen` 标记）
- **THEN** 不再显示首次安装告知弹窗

### Requirement: 用户协议内容重写
系统应提供内容详尽、表述严谨的用户协议，侧重法律责任界定。

#### Scenario: 协议内容覆盖范围
- **WHEN** 用户查看完整用户协议
- **THEN** 协议应包含以下章节：定义条款、软件性质声明、授权许可、用户声明与保证、禁止行为、用户责任原则、知识产权、风险披露（法律风险+技术风险）、免责声明、责任限制、赔偿条款、隐私与数据处理、未成年人保护、协议修改与终止、争议解决、一般条款

#### Scenario: 协议措辞风格
- **WHEN** 用户阅读协议内容
- **THEN** 协议采用专业法律术语及复杂句式，侧重开发者责任豁免和用户责任界定

## MODIFIED Requirements

### Requirement: 状态栏法律信息入口移除
状态栏原有的"用户协议"一级按钮应移除，法律信息入口迁移至三级菜单。

#### Scenario: 状态栏不再显示用户协议按钮
- **WHEN** 用户查看状态栏
- **THEN** 状态栏右侧区域不再包含"用户协议"文字按钮，仅保留授权状态、运行状态等信息
